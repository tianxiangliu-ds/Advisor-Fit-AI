# 怎么接上向量模型（给不熟悉这类配置的人看）

> **先看这一句：你现在已经有一个能用的了，这篇文章是可选的。**
>
> 本机模型 `bge-small-zh-v1.5` 已经下好并配进 `.env`，真语义召回**已经在生效**。
> 下面讲的是"改用云端接口"这条备选路线——只有在特定情况下才值得折腾。

---

## 一、先搞清楚：为什么不能用你现在的 DeepSeek Key

你 `.env` 里已经有一个 `LLM_API_KEY`（DeepSeek 的），它负责"读懂、总结、判断、写"。
但**向量不是它管的事**：

| | 干什么 | DeepSeek 提供吗 |
|---|---|---|
| **大模型接口**（你已有的那个 Key） | 读懂文字、写总结、做判断 | ✅ 提供 |
| **向量接口**（这篇文章要配的） | 把一句话变成一串数字，用来算"两句话像不像" | ❌ **不提供** |

所以这不是"再填一次同样的 Key"，而是要**另外去一家支持向量的服务**申请。

**一句话记住**：DeepSeek 的 Key 填进向量配置里不会生效。

---

## 二、向量到底是干什么的（一句人话）

把一句话变成一串数字（比如 512 个小数），**意思越接近的两句话，这两串数字越像**。

有个地方很需要它：系统在"方向找导师"里，靠关键词去找导师。但关键词有个死板的毛病——

- 你写「**图谱的构建方法**」
- 导师写的是「**知识图谱与实体抽取**」

字面对不上，系统就说"没找到"。可这两句话意思明显是一回事。

**向量就是用来补这一层的。** 它不算字面，算"像不像"，于是能把这种人捞回来。

---

## 三、什么时候值得去申请 Key

| 你的情况 | 建议 |
|---|---|
| 只想自己用、机器性能够 | **不用折腾**，本机模型已经够好 |
| 想部署到服务器 / 演示站（机器弱、没 GPU） | 值得申请，云端不占本机资源 |
| 导师库很大（几万条以上）、要频繁检索 | 值得申请，云端更快 |
| 只是想把功能跑通看看 | **不用折腾**，现在已经通了 |

## 四、去哪申请（选一家就行）

下面几家都提供**接口格式相同**的向量服务（行业里叫"OpenAI 兼容"，意思是
"填法跟 OpenAI 一模一样，换个网址和名字就行"）：

| 服务商 | 网址 | 免费额度 | 备注 |
|---|---|---|---|
| **硅基流动** | cloud.siliconflow.cn | 有免费额度 | 中文模型多，价格便宜，**推荐新手先试这家** |
| 智谱 AI | open.bigmodel.cn | 有免费额度 | 国内老牌 |
| 阿里云百炼 | bailian.console.aliyun.com | 有新用户额度 | 企业级，配置略多 |
| OpenAI | platform.openai.com | 无（要充值） | 国内访问不便 |

> ⚠️ 上面的网址和免费政策是**我按常识写的，会变**。申请前请以对方官网为准。
> 我没有这几家的账号，**没法替你验证**——所以第五步的"自检"很重要。

**申请流程大同小异**（以硅基流动为例）：

1. 打开官网，注册（一般手机号就行）；
2. 进"控制台 / API 密钥"页面；
3. 点"新建密钥"，会得到一串 `sk-` 开头的东西；
4. **把它复制下来**（很多网站只显示一次）。

## 五、填进 `.env`（照着抄）

打开项目根目录下的 `.env` 文件（用记事本就行）。你会看到我之前加的一段，
里面有一行是被 `#` 注释掉的方案二。**把 `#` 去掉，填上你的信息**：

```dotenv
# 方案二（调接口，需要自己去申请 Key，填完可把上面那行注释掉）：
EMBEDDING_BASE_URL=https://api.siliconflow.cn/v1
EMBEDDING_MODEL=BAAI/bge-m3
EMBEDDING_API_KEY=sk-你申请到的那一串
```

**三行分别是什么：**

| 这一行 | 填什么 | 注意 |
|---|---|---|
| `EMBEDDING_BASE_URL` | 服务商的网址 | **结尾要带 `/v1`**（阿里那家是别的路径，看它文档） |
| `EMBEDDING_MODEL` | 模型名 | **必须和网址是同一家的**，不能混 |
| `EMBEDDING_API_KEY` | 你复制的 Key | 等号两边**不要加引号、不要加空格** |

**同时把本机模型那行注释掉**（在前面加 `#`），否则两套配置会打架：

```dotenv
# EMBEDDING_LOCAL_MODEL=.models/bge-small-zh-v1.5
```

改完存盘。**不需要重启什么服务**，下次运行命令就会读到。

## 六、验证（这一步别省）

在项目目录下运行：

```powershell
.\.venv\Scripts\python.exe scripts\check_embedding.py
```

**看三个地方：**

**① 第二行必须是「是不是真语义：是」**

```
后端：api:BAAI/bge-m3
是不是真语义：是          ← 这行是"是"才算接通
```

如果显示"否"，说明配置没被读到，或者加载失败了——**下面会打印原因**，照着改。

**② 必须出现「[通过] 拿到向量，维度 xxx」**

没通过会打印具体报错（Key 错了、网址错了、余额没了，都会写清楚）。

**③ 最后三组对照必须都能分辨**

```
查询                    相关     无关    区分度   判定
知识图谱                0.715   0.355   +0.360   可以分辨
图神经网络与推荐系统      0.524   0.236   +0.288   可以分辨
数字人文与古籍数字化      0.623   0.186   +0.437   可以分辨
3/3 组能分清「相关」与「无关」。
```

**这一条最重要。** 很多接口能返回数字，但**模型选错了**（比如用了个只会英文的模型），
算出来的相似度就没有区分度——接上去等于白接，而且**界面上完全看不出异常**。
这三组对照就是专门用来抓这种事的。

## 七、出问题怎么排查

| 报错里出现 | 多半是 | 怎么办 |
|---|---|---|
| `401` / `Unauthorized` / `invalid api key` | Key 填错或已失效 | 重新复制一次，注意别把空格也复制进去 |
| `404` / `model not found` | 模型名拼错，或和网址不是同一家 | 去对方官网的控制台复制准确的模型名 |
| `Connection` / `Timeout` | 网址写错，或网络不通 | 检查 `BASE_URL`，确认结尾是 `/v1` |
| `余额` / `quota` / `insufficient` | 免费额度用完了 | 充值，或换回本机模型 |
| 显示「是不是真语义：否」 | 三行没配齐，或本机模型那行没注释掉 | 检查 `.env` 里是否恰好只剩一套配置 |
| 三组对照「几乎分不开」 | 模型选得不对 | 换一个**中文/多语言**模型重试 |

**任何情况下想退回去**：把三行接口配置注释掉、把本机模型那行取消注释，
就又回到现在这个能用的状态。
